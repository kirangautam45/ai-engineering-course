# Day 45: 🎓 Demo Day

Today every student presents their capstone: a working, deployed AI app. Congratulations on getting here: 45 days ago many of you had never called an LLM API.

## Format

- **3 minutes** per demo (follow your Day 44 script), then **2 minutes** of questions
- Present from the **live URL**, with your backup recording ready
- Classmates fill in a short [feedback form](feedback-form.md) for each demo

## How demos are assessed

See [`rubric.md`](rubric.md). In short:

| Area | Weight |
|---|---|
| It works and is deployed | 30% |
| Quality, measured with evals | 25% |
| Safety and responsible use | 15% |
| Code and README | 15% |
| The demo itself | 15% |

## Good questions to ask each other

- What was the hardest bug, and how did you find it?
- Which question does your app get wrong, and why?
- What does one question cost, and how would that change with 1,000 users?
- What would you change if you started again?

## After the course

You now know how to call LLM APIs, write good prompts, stream answers, use tools, build RAG with hybrid search and reranking, evaluate everything, and deploy it safely. Some next steps:

- **Keep improving your capstone**: add the "should have" features, grow your eval set with real users' questions
- **Go deeper on agents**: the [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk) and multi-step tool use
- **Read the docs**: [Claude documentation](https://docs.claude.com) has guides for every feature used in this course
- **Share your work**: put the live URL and your eval results on your GitHub profile and CV. A deployed, measured project stands out
- **Teach it**: explaining RAG or evals to someone else is the fastest way to find the gaps in your own understanding
